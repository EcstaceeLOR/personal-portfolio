# Ecstacee — Personal Portfolio

A single-page, data-driven portfolio for Abdulmuiz Ademola Abdulkabir (Ecstacee).

## Local development

```bash
npm install
npm run dev
```

## Updating content

Most portfolio content lives in `data/portfolio.ts`.

- Add or edit featured work in `projects`.
- Add skills in `skills`.
- Add experience in `experience`.
- Add awards in `achievements`.
- Add hackathon entries in `hackathons`.
- Add leadership roles in `leadership`.
- Update social profiles in `socials`.

Images live in `public/images/`. Replace an image while keeping the same filename if you want the layout to update without editing components.
